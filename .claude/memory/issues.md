# Macast 2.0 已知问题与解决方案

**最后更新**: 2026-07-05

---

## 技术债务

### TD-001: 原始代码依赖过时
- **来源**: Macast-main/
- **问题**: 依赖库版本老旧（CherryPy、pystray 等）
- **影响**: 安全风险、兼容性问题
- **解决**: 全面升级依赖或替换为现代方案

### TD-002: 原始 GUI 代码废弃
- **来源**: macast/gui.py
- **问题**: 使用 pystray 实现系统托盘，与 Tauri 架构冲突
- **影响**: 需要完全重写前端
- **解决**: 由 Tauri 前端替代，gui.py 仅作参考

### TD-003: Python 进程管理
- **来源**: 架构设计
- **问题**: Rust 需要管理 Python 子进程生命周期
- **影响**: 崩溃恢复、资源清理
- **解决**: 实现 PythonBridge 模块，包含健康检查和自动重启

## 兼容性问题

### COMP-001: WebKit CSS 兼容性
- **平台**: macOS
- **问题**: 某些 CSS 特性在 WebKit 中不支持或表现不同
- **解决**:
  - 使用 `@supports` 检测
  - 避免最新 CSS 特性
  - 跨平台测试

### COMP-002: 媒体格式支持差异
- **平台**: macOS vs Windows
- **问题**: WebKit 对某些视频格式解码支持有限
- **解决**: 前端不负责解码，全部交给后端处理

### COMP-003: 系统特效 API 差异
- **平台**: 全平台
- **问题**: 每个平台的窗口特效 API 不同
- **解决**: 使用 tauri-plugin-vibrancy 抽象层

## 架构风险

### RISK-001: Python 启动延迟
- **描述**: Python 进程启动可能较慢
- **缓解**:
  - 预启动 Python 进程
  - 显示加载动画
  - 异步初始化

### RISK-002: 端口冲突
- **描述**: DLNA 服务需要固定端口，可能与其他应用冲突
- **缓解**:
  - 端口自动检测
  - 配置文件可修改
  - 启动时检查端口可用性

### RISK-003: 防火墙拦截
- **描述**: SSDP 多播可能被防火墙拦截
- **缓解**:
  - 启动时检测网络环境
  - 提供防火墙配置提示
  - 文档说明
