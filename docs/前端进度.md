## 项目结构

```
src/
├── main.ts                    # 入口
├── App.vue                    # 根组件（主题检测）
├── router/index.ts            # Hash 路由
├── stores/                    # Pinia 状态管理
│   ├── device.ts              # 设备列表 + 事件监听
│   ├── media.ts               # 媒体输入状态机
│   ├── cast.ts                # 投屏状态 + 事件监听
│   └── settings.ts            # 设置管理
├── views/
│   ├── HomeView.vue           # 主页面
│   └── SettingsView.vue       # 设置面板
├── components/
│   ├── TitleBar.vue           # 自定义标题栏
│   ├── MediaInput.vue         # 拖拽区 + URL 输入
│   ├── DeviceList.vue         # 设备列表容器
│   ├── DeviceCard.vue         # 设备卡片
│   ├── CastControl.vue        # 投屏控制条
│   └── Footer.vue             # 底部提示
├── api/commands.ts            # Tauri invoke 封装
├── types/                     # TypeScript 类型定义
├── locales/                   # 国际化资源
└── styles/                    # CSS 变量 + 全局样式
```

## 启动命令

```bash
# 浏览器开发（mock 数据）
npm run dev

# Tauri 桌面预览
npm run tauri dev
```
