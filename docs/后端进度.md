### 3. 实现的命令 (16 个)

#### 设备管理
- `get_devices` - 获取设备列表
- `refresh_devices` - 触发扫描
- `set_default_device` - 设置默认设备
- `rename_device` - 重命名设备
- `remove_device` - 移除设备

#### 投屏控制
- `start_cast` - 开始投屏
- `stop_cast` - 停止投屏
- `pause_cast` - 暂停投屏
- `resume_cast` - 恢复投屏
- `seek_cast` - 跳转位置
- `get_cast_state` - 获取状态
- `set_volume` - 设置音量
- `set_mute` - 设置静音

#### 媒体解析
- `parse_media` - 解析媒体 (文件/URL)

#### 设置管理
- `get_settings` - 获取设置
- `save_settings` - 保存设置

## 关键决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| DLNA 角色 | 双向 (渲染器 + 控制端) | 支持接收和发送投屏 |
| MPV 职责 | 仅接收投屏 | 前端选择文件直接投屏到电视 |
| HTTP 框架 | aiohttp | 异步支持，替代 CherryPy |
| 插件系统 | 移除 | 简化架构 |
| 进程通信 | stdin/stdout JSON | 零端口占用，自动生命周期管理 |
